运算强度 = ops / byte。强度低（depthwise、逐元素）时 DDR 成墙；强度高时 MAC 才是墙。NPU 编译器的 tiling/融合就是在抬有效强度。

为什么 IC 要盯 bit
  • 位宽决定乘法器面积：8×8 与 24×24 尾数不是一个量级——02 课「计算便宜」的电路版。
  • 符号与饱和：INT8 −128 的绝对值比 +127 大 1；round 后溢出是截断还是饱和，软件/硬件必须一致。
  • 累加链：一拍 1024 个 INT8 乘积进 INT32，中途哪一级进位错都会让整层悄悄偏。
  • 布局：NC1HWC2 把 16 个通道打包，正好铺一排——bit 在总线上「排成什么样」就是编译器的排布方案。

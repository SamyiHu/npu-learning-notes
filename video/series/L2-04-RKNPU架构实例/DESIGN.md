# DESIGN.md — NPU Lab 讲解视频

## Style Prompt

Silicon die floorplan meets measurement instrument. A dark, warm-tinted void with copper
traces and hairline rules, where the subject is not "a tech dashboard" but an actual chip
being explained. Every scene should feel like an engineering diagram coming alive: blocks
snap into place, data flows along visible paths, counters tick up. Restrained, technical,
warm — never neon cyan, never equal card grids.

## Colors

- void `#0B0A12` — background
- panel `#12111A` — diagram blocks
- line `#2C2839` — hairline rules, grid
- ink `#EDE8F5` — primary text
- muted `#918AA3` — secondary text
- copper `#D4895A` — primary accent (data, active paths, highlights)
- ok `#5BBF9A` — secondary accent (throughput, verified states)
- flux `#E85D7A` — tertiary accent (bottleneck, warnings, CPU fallback)

## Typography

- Display: Bahnschrift (DIN-like, technical numerals)
- Body: Segoe UI / Microsoft YaHei for Chinese
- Data: Cascadia Code for numbers, paths, commands

## What NOT to Do

- No cyan-on-near-black tech dashboard look
- No equal-size feature card grids
- No large rounded bubbles or pill-shaped everything
- No purple-to-blue gradients
- No pure `#000` or pure `#fff`
- No bounce/elastic easing — mechanical, precise motion only

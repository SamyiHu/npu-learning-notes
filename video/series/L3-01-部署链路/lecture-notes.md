# L3-01 · 部署链路：ONNX 到 .rknn

> 五步流水线与工具链家族
> 分级：L3 · 时长 4 分钟 · 配音 Edge Neural TTS · 配乐程序化合成（seed 31, 92 BPM）

## 学习目标

独立完成一次模型转换，理解每一步在做什么

## 逐段讲解

1. 这一集进入实战。目标是把一个模型转换、板端跑起来。
2. 先说部署的五个步骤。训练模型，导出 ONNX，转换成 RKNN，推到板子，板端加载推理。
3. 为什么要中间过一层 ONNX？因为训练框架太多，芯片厂商不想一家一家适配。ONNX 是大家公认的中间格式。
4. 为什么 RKNN 不能跨芯片？因为它是针对具体芯片编译出来的。里面锁定了算子清单、数据排布、量化方案。
5. 在电脑上装工具链。官方只有 Linux 的包，所以 Windows 上要走 WSL。
6. 这一步配置目标芯片和输入归一化参数。这里的均值方差必须和训练时一致，否则精度会掉。
7. 第二步读入 ONNX 模型。
8. 第三步构建。这一步会做量化，工具链会读取你的校准集，统计每层范围，定出每层的缩放比例。
9. 第四步导出，得到 RKNN 文件。
10. 第五步可以在电脑上先仿真。不碰板子就能验证转换是否正确。
11. 工具链家族要分清。Toolkit2 在电脑上转换和仿真。lite2 是板端的 Python 接口。librknnrt 是板端的 C 语言运行时。
12. 这一集要记住的是：转换的正确性，可以先在电脑上验证，再推到板子。

## 练习

1. 手算：写出五步链路和对应的五个调用。
2. 解释：为什么 RKNN 不能跨芯片直接运行？
3. 调试：电脑上仿真正常，板端结果不同，先比较什么？

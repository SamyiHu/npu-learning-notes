L2-03 · 硬件原理

对称量化

权重通常用这一种
1scale = max|w| / 127
2q = round(w / scale)
让最大正值对准 +127
对称量化的缩放比例，等于最大绝对值除以一百二十七。把每个权重除以这个比例，四舍五入成整数。
L2-03 · 硬件原理

反量化

用整数乘回比例
1x ≈ q × scale
2误差 ≤ scale / 2
是确定性上界
反量化就是用整数乘回比例。单个数值的误差不超过半个格子。

为什么要非对称？

ReLU 之后的激活全是非负
  • 对称会浪费一侧格子
  • 所以加一个零点 z
ZERO POINT
z
int
激活值通常全是非负的，用对称量化会浪费一侧的格子。所以改用非对称量化，多一个零点。
L2-03 · 硬件原理

非对称量化公式

零点把浮点的 0 挪到对应格子
1q = round(x / scale) + z
2x ≈ (q − z) × scale
z 不一定是 0
量化公式是先用浮点值除以比例、再取整，最后加零点。反量化是整数减零点，再乘比例。

一层卷积在硬件里算什么

全是整数
1INT8 × INT8 → 乘积约 16 bit
2点积累加 → INT32
累加器必须够宽
现在看一层卷积。权重是八比特的整数，输入也是八比特的整数。乘起来是十六比特。

L2-03 · 提醒

为什么用 INT32？

几百上千个乘积累加
  • INT8 会溢出
  • INT32 把溢出风险降到很低
一个点积要把几百上千个乘积累加起来，所以累加器要用三十二位，避免溢出。
L2-03 · 硬件原理

层与层之间要做什么？

重新缩放到下一层格式
1Y = Y × (s_w × s_x / s_y)
2→ round → saturate
这一步叫 requantization
但这一层的输出，还是要用下一层的格式。所以要在层与层之间重新缩放。

L2-03 · 提醒

量化是一条链

环环相扣，缺一不可
  • scale
  • 零点
  • 舍入规则
  • 累加器宽度
  • requant 舍入与饱和
这个步骤叫 requantization：按权重比例、输入比例、输出比例重新缩放，四舍五入，然后饱和到下一层范围。

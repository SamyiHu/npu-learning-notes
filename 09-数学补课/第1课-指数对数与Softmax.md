## 一、核心一句

**推理几乎不用微积分；但 Softmax 的 e^x、损失里的 log、数值稳定，需要你认识指数和对数。**
目标：会算、会估量级、会防溢出——不是应试推导。

---

## 二、指数 e^x：只记这三条

```
e^0 = 1
e^x 随 x 增大而爆炸增大
e^x > 0 恒成立
```

### 数量级感觉

| x | e^x（约） |
|---|---|
| 0 | 1 |
| 1 | 2.7 |
| 2 | 7.4 |
| 5 | 148 |
| 10 | 22026 |
| 20 | 4.8e8 |

**x 差一点，e^x 差很多**——Softmax 就是靠这个「拉开差距」。

---

## 三、Softmax 手算（注意力/分类共用）

```
分数 s = [1, 2, 1]
e^s    ≈ [2.72, 7.39, 2.72]
sum    ≈ 12.83
权重   ≈ [0.21, 0.58, 0.21]   和为 1
```

### 为什么要先减 max（数值稳定）

若 s 里有 1000：

```
e^1000 → 计算机直接 inf/NaN
```

工程写法：

```
s' = s - max(s)
softmax(s') 与 softmax(s) 数学相同，数值安全
```

这是 IC/嵌入式都要懂的 **数值卫生**。

---

## 四、温度 T（可选加深）

```
softmax(s / T)
T 大 → 更均匀（多听各方）
T 小 → 更尖（赢家通吃）
```

T→0 时近似 argmax。学习舱原理剧场 P4 可拖。

---

## 五、对数 log：损失和「似然」

```
log(1) = 0
log(0+) → -∞
0 < p < 1 时 log(p) < 0
```

交叉熵（分类损失）直觉：

```
真实类概率 p 越接近 1 → -log(p) 越接近 0（罚得轻）
p 接近 0 → -log(p) 爆炸（罚得重）
```

**训练**用它拉权重；**推理**通常不再算损失。  
所以 NPU 部署可以几乎不实现 log 硬件——但你要知道训练在优化什么。

---

## 六、和 NPU 的接口

| 数学件 | 出现在 | 硬件谁做 |
|---|---|---|
| e^x / softmax | 注意力、分类头 | 常 CPU 或小查表；大 GEMM 在 NPU |
| log | 训练损失 | 不在端侧 NPU |
| 乘加 | 全部 | MAC 阵列 |

---

## 七、口诀

- e 拉开差距，softmax 变概率
- 先减 max 再 exp，防 inf
- log 把「很错」罚到爆炸；训练用，推理少见
- 推理主菜是乘加，不是微积分

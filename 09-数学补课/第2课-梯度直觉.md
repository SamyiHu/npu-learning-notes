# 数学补课 第2课：梯度直觉——为什么权重会动（不推导）

> 学习日期：2026-08（补课线）
> 阶段：09-数学补课
> 前提：第1课 Softmax；知道「训练调权重、推理权重固定」
> 方式：只建直觉，服务「刨根问底」；**NPU 主线不依赖推导**

---

## 一、核心一句

**训练 = 让损失 L 变小：沿着「L 对每个权重的斜率」反方向挪一小步。**
斜率就是梯度；反向传播是高效算梯度的算法。你做推理时梯度已经「用完了」。

---

## 二、损失是什么

```
预测 ŷ  vs  标签 y  →  一个数 L（越小越好）
```

分类常见交叉熵（见第1课）；回归常见 MSE：

```
L = (ŷ - y)²
```

---

## 三、单权重的直觉（一维）

```
w  →  L(w)  是一条曲线
斜率 dL/dw > 0  →  w 减小一点，L 往下走
斜率 < 0        →  w 增大一点
步长 η（学习率）控制挪多少
```

```
w ← w - η · dL/dw
```

**没有魔法：就是「看斜率、往下坡走」。** 深度网络难在链太长、非线性多，不是单点微积分有多玄。

---

## 四、链式法则（只记结构）

```
L 对前面层的梯度 = 后面各层局部斜率的连乘
```

这就是「反向传播」：从输出往输入一层层乘回去。  
和数字电路里 **反向敏感度/故障传播** 的感觉类似——前面的扰动会被后面放大或抹掉。

---

## 五、ReLU 的梯度

```
z > 0:  梯度是 1（原样传）
z ≤ 0:  梯度是 0（断掉）
```

- 好处：计算极简（硬件也极简）  
- 代价：负区「神经元死亡」不再学习（训练问题，不是推理问题）

---

## 六、为什么推理可以「几乎不谈高数」

| 训练 | 推理（NPU） |
|---|---|
| 要 dL/dw | 权重已冻结 |
| 要优化器状态 | 无 |
| 常 FP32/BF16 | 常 INT8/FP16 |
| GPU 集群 | 端侧 NPU |

所以你的主线可以 **跳过完整高数**，只保留：

1. 损失越小越好  
2. 梯度=斜率，下坡  
3. 反向=链式连乘  
4. 推理不再更新 w  

---

## 七、和验证工作的类比

| 训练概念 | 验证类比 |
|---|---|
| 损失 | score / mismatch 计数 |
| 梯度 | 哪个输入比特影响输出 |
| 学习率过大 | 激励步长过大导致不收敛假象 |
| 过拟合 | 测试向量只覆盖典型 corner |

---

## 八、口诀

- 损失是分数，越小越好  
- 梯度是斜率，往下坡挪  
- 反向是链式乘  
- 推理冻结权重，NPU 只做前向

# NPU Lab

这是一个从零基础到 RK3576/RKNN 推理实践的中文学习仓库。

## 新手入口

1. 先读 [00-开始这里.md](00-开始这里.md)。
2. 基础不够时读 [00-小白基础补课.md](00-小白基础补课.md)。
3. 遇到术语查 [00-术语表.md](00-术语表.md)。
4. 按 [学习路线.md](学习路线.md) 顺序学习。
5. 实践统一走 [05-实践/golden-path/README.md](05-实践/golden-path/README.md)。
6. 跑通第一个模型后，读 [05-实践/第3课-模型实战全链路.md](05-实践/第3课-模型实战全链路.md)：训练/LoRA、浮点基线、裁剪、量化各在哪台机器做，以及调试四层。
7. 想深挖“为什么只能这么设计”时，按 [论文清单.md](论文清单.md) 读论文（56 篇，按课程对号，写清了读哪几节、在板子上怎么验证）。

## 学习方式

每课都完成三件事：手算一个小例子、做小白练习、记录一条实验结果。  
互动演示可以打开 `index.html`，讲义源文件位于各阶段目录。

## 范围与边界

这套教程覆盖“从零基础到在 RK3576 上完成模型转换、部署、性能测量和基础验证”的完整链路，**不覆盖**：

- 模型训练、微调与数据集工程（只在 09 课讲梯度直觉，不教训练）；
- NPU RTL 设计 / DV 验证实操（各课只有“IC 验证视角”小节，不是实验课）；
- NPU 编译器 / 任务列表的内部实现（公开资料有限，03 课按社区逆向标注）。

需要深入时，优先查 `资料索引.md` 里的官方仓库与文档，尤其是 rknn-toolkit2 的算子支持章节（v2.5.0 起单独成册为《算子支持与约束参考》）和 rknn_model_zoo 的 benchmark。

# 大模型笔记 第2课：注意力机制——大模型的心脏

> 学习日期：2026-08-06
> 阶段：06-大模型与Transformer
> 前提：掌握 CNN 管道、点积 = 相关度（第1.5课）

---

## 一、核心一句话

**大模型的任务 = 预测下一个词。注意力 = 每个词"看"所有其他词，按相关度吸收上下文。**

## 二、为什么 CNN 不够，必须要有注意力

```
"小明走进教室，他把书包放在桌上，然后……"
问: "他"指谁？ → 小明（在 20 个词之前）
```

CNN 的核只看旁边 9 个像素，**天生看不见远处**。而语言恰恰是"远处的词决定意思"。所以需要一种机制：**让每个词能"看"到句子里的所有其他词** —— 这就是注意力。

## 三、注意力 = 查资料（Q / K / V）

```
你脑子里的问题 = Query（Q，你要找什么）
每本书的标题   = Key（K，这本书是什么）
书的内容       = Value（V，这本书讲了什么）
```

流程：拿 **Q** 和每本书的 **K** 比对"像不像" → 像的权重高 → 按权重把 **V** 加权汇总。

**自注意力**：把这套用到词身上，**每个词都当一次"查资料的人"，去"看"句子里的所有其他词。**

## 四、四步走（带手算：我 爱 猫）

词先变成数字（embedding，此处用二维）：

```
我 = [1, 0]
爱 = [1, 1]
猫 = [0, 1]
```

（真实模型里 Q/K/V 是三个学出来的变换，此处为讲直觉假装 Q=K=V=词本身。）

**第1步**：拿"爱"的 Q 去和每个词的 K 做**点积**算相关度：

```
相关度(爱, 我) = [1,1]·[1,0] = 1
相关度(爱, 爱) = [1,1]·[1,1] = 2
相关度(爱, 猫) = [1,1]·[0,1] = 1
```

**第2步**：分数转成"加起来=1"的权重（分高权重高）：

```
权重 = [0.21, 0.58, 0.21]     ← "爱"和"爱"最像，权重最高
```

**第3步**：按权重把所有词的 V 加权平均：

```
"爱"的新表示 = 0.21×[1,0] + 0.58×[1,1] + 0.21×[0,1] = [0.79, 0.79]
```

**第4步**：每个词都做一遍同样的事（并行）。

**"爱"原来的表示 [1,1] 变成了 [0.79, 0.79]——里面混进了"我"和"猫"的信息。这就是"词理解了上下文"。**

## 五、三个老朋友

1. **点积 = 相关度**：第1.5课说过"点积 = 默契度"，注意力用的就是它
2. **加权平均 = 乘加**：注意力本质 = 一堆矩阵乘法（Q×Kᵀ 算相关度，再 ×V 加权）。底层还是"乘加 + 掰弯"
3. **所有词同时算 = 并行**：每个词的注意力互相独立 → 正好是矩阵乘法 → NPU 最喜欢的形状

## 六、为什么"看很远"、为什么"贵"

- **看得远**：相关度是"每个词 × 每个词"，**跟距离无关**。隔 20 个词和隔 1 个词算法一样 → "他"能认出 20 词前的"小明"
- **贵（N²）**：N 个词要算 N×N 次相关度。**上下文翻倍，算力翻 4 倍**（平方增长，不是指数）。这就是长上下文贵的根本原因

```
上下文 1000 词 → 1000×1000 = 100 万次
上下文 2000 词 → 2000×2000 = 400 万次   ← 词翻倍，算力 4 倍
```

NPU 跑大模型，头号要优化的就是 N² 这一块（KV 缓存、稀疏注意力……）。

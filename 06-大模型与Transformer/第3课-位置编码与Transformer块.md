# 大模型笔记 第3课：位置编码与完整的 Transformer 块

> 学习日期：2026-08-06
> 阶段：06-大模型与Transformer
> 前提：已学注意力四步（Q/K/V、点积、加权平均）

---

## 一、核心一句话

**注意力分不清顺序 → 加"位置标签"解决。完整的 Transformer 块 = 自注意力 + 残差 + 归一化 + MLP，重复 N 次。**

## 二、注意力的"坑"：分不清顺序

相关度只在乎"有哪些词、像不像"，**完全不在乎先后顺序**。

```
猫 追 狗     →  猫[1,0] 追[0,1] 狗[1,1]
狗 追 猫     →  狗[1,1] 追[0,1] 猫[1,0]
```

**两个句子的输入是完全一样的三个数字，只是顺序不同。** 注意力算出来的相关度也一模一样 → 模型把"猫追狗"和"狗追猫"当成同一个东西。这叫**词袋陷阱**：只看到有哪些词，看不到顺序，等于没看懂语言。

## 三、补洞：位置编码（Positional Encoding）

**让每个词知道"自己在第几个位置"。** 给每个位置配一个独一无二的标签，**加到词的表示上**：

```
词的数字      +   位置标签     =   词的新表示
[1, 0]            [1, 1]           [2, 1]
（猫的内容）   （"我在第0位"）   （猫 + 位置）

同一个"猫"：
  在第0位: [1,0] + [1,1]  = [2,1]
  在第2位: [1,0] + [-1,1] = [0,1]     ← 数字不同了！
```

于是：

```
猫追狗 → 猫[2,1] 追[1,0] 狗[0,2]
狗追猫 → 狗[2,2] 追[1,0] 猫[0,1]     ← 两个句子终于不一样了
```

模型从此能区分"谁在前谁在后"。最早的 Transformer 用固定正弦/余弦波形，现在很多模型用学出来的或 RoPE（旋转位置编码）——**本质都一样：把"位置"混进词的表示里。** 对硬件：只是加法/查表，几乎不要成本。

## 四、多头注意力（Multi-Head Attention）

**一个 Q/K/V 组 = 一个"看问题的角度"。** 一句话里同时有好几种关系：

```
"小明看到一只猫，他决定追它。"
  · "他"指代谁？        → 指代关系
  · 谁是主语、谁是宾语？ → 语法关系
  · 语气是什么？        → 语气
```

一个头只能盯一种关系 → 放**多个头**，每头自己一套 Q/K/V，各抓一种，最后拼起来。

> 类比：一组人开会，有人盯逻辑、有人盯情绪，最后综合意见。

对硬件友好：**多头 = 多组矩阵乘法，天然并行。**

## 五、完整的 Transformer 块（基本单元）

```
输入
 ↓
[自注意力] ──→ 结果 ─┐
                      │ ← 残差连接：结果 + 原输入
 ↓                  │
[归一化 LN]          │
 ↓
[MLP] ──────→ 结果 ─┼─
                      │ ← 残差连接：结果 + 原输入
 ↓                  │
[归一化 LN]          │
 ↓
 输出 → 下一块

（这个块重复 N 次，就是模型的"深度"）
```

两个新零件：

- **残差连接（Residual）**：`输出 = 原来的 + 处理的结果`，像改作文留原稿。防止信息一层层"传丢"，是深层网络能叠几百层还训练得动的关键
- **归一化（LN）**：即之前学的归一化（Transformer 里用 LayerNorm），管数值稳定

**对比 CNN 一句话：CNN 的基本单元 = [卷积 + 激活]（处理局部）；Transformer 的基本单元 = [自注意力 + MLP]（处理全局关联）。**

## 六、它到底是怎么"说话"的？（生成 = 循环预测）

```
预测"下一个词最可能是谁" → 把预测的词接到句子尾巴
  → 重新算一遍 → 再预测下一个 → 接到尾巴 → ...
```

**聊天 = "预测下一个词"的循环跑了一遍又一遍。** 每生成一个词，都要把整个上下文重新过一遍——这也是它"贵"的原因（硬件视角见后续课程）。

# 第 3 课笔记：池化（Pooling）与归一化（BN）

> 学习日期：2026-08-06
> 阶段：01-神经网络基础
> 前提：已掌握第 1 课（全连接=矩阵乘法）、第 1.5 课（线代）、第 2 课（卷积）

---

## 一、核心一句话

**池化 = 没权重的"压缩"，把特征图变小；归一化 = 把数值拉回"友好区间"。**
两个都不算矩阵乘法，属于神经网络里的"轻计算"——但对硬件来说，少一种算子 = 少一块电路。

---

## 二、第 1 部分：池化（Pooling）

### 2.1 为什么需要池化

卷积层的输出特征图往往很大（一张 224×224 的图，经过卷积后可能有很多通道）。数据量太大，计算和存储都吃不消。**池化的作用就是"下采样"：把图变小，只留最"有用"的信息。**

池化**没有权重**——这是它和卷积、全连接最本质的区别。它只是"看图说话"：

### 2.2 Max Pooling（最大池化）—— 最常用

规则：在一个小窗口里，**取最大值**。窗口滑动方式和卷积一模一样。

例：4×4 特征图，2×2 窗口，步长 2，无填充：

```
输入特征图:
  1  3  2  4
  5  6  8  7
  9  0  1  2
  3  4  5  6

窗口1（左上）→ [1 3 / 5 6] → 取 max = 6
窗口2（右上）→ [2 4 / 8 7] → 取 max = 8
窗口3（左下）→ [9 0 / 3 4] → 取 max = 9
窗口4（右下）→ [1 2 / 5 6] → 取 max = 6

输出特征图:
  6  8
  9  6
```

每个窗口只看"有没有东西"，取最强的那个响应。**直觉：窗口内最显著的特征留下了，其余细节丢掉。**

### 2.3 Average Pooling（平均池化）

规则：窗口内**取平均值**。同一个例子：

```
窗口1: (1+3+5+6)/4 = 15/4 = 3.75
窗口2: (2+4+8+7)/4 = 21/4 = 5.25
窗口3: (9+0+3+4)/4 = 16/4 = 4.00
窗口4: (1+2+5+6)/4 = 14/4 = 3.50

输出特征图:
  3.75  5.25
  4.00  3.50
```

Max 池化更常用（保留"有没有特征"），Average 池化更平滑。早期网络（LeNet）结尾常用 Average 池化做"全局平均"。

### 2.4 输出尺寸公式——和卷积一样

```
输出尺寸 = (原图尺寸 - 窗口尺寸) / 步长 + 1
例: (4 - 2)/2 + 1 = 2     ← 上面 4×4 → 2×2
```

### 2.5 池化的三个作用

1. **降维减数据**：特征图变小 → 后续计算量、存储量都下降
2. **平移不变性（直觉）**：特征"大概在这一片"就行，具体在哪一格不重要。猫从画面左边移到右边，max 池化后仍然能"看到"这个特征 → 网络更鲁棒
3. **防过拟合**：细节被丢掉，模型不容易死记训练集上的噪声

### 2.6 小贴士（现代趋势）

现在很多新网络（如 ResNet）**用步长 2 的卷积代替池化**——同样能把图变小，但权重是"学出来"的，比固定规则更灵活，还能少实现一种算子。理解池化后，看到"stride=2 conv"就知道它在干池化的事。

## 三、第 2 部分：归一化（Batch Normalization，BN）

### 3.1 问题：数值越传越"疯"

神经网络一层层传下去，某些通道的输出可能越来越大、或集中在某个离谱的范围（比如全是 1000 多）。数值一大，激活函数容易"饱和"（比如 Sigmoid 两端的梯度趋近 0），训练就学不动了。**BN 的目的：把每一层输出的数值，强制拉回"均值约 0、方差约 1"的区间，让数据始终处于友好范围。**

### 3.2 BN 训练时干什么

对**每个通道**，看当前**这一批（batch）样本**在该通道的所有取值，算出：

```
μ    = 均值            （这批数据的中心）
σ²   = 方差            （这批数据有多散）
```

然后归一化：

```
x̂ = (x - μ) / √(σ² + ε)     ε 是防止除以 0 的小数
```

再学两个可调参数 γ（缩放）和 β（平移），目的是让网络**保留"想用什么范围就用什么范围"的自由**（否则强制变标准正态可能太死板）：

```
y = γ·x̂ + β
```

### 3.3 手算一个小批量

某个通道在 4 张样本图上的取值：`[2, 4, 6, 8]`

```
μ = (2+4+6+8)/4 = 5
σ² = ((2-5)²+(4-5)²+(6-5)²+(8-5)²)/4 = (9+1+1+9)/4 = 5
σ ≈ 2.24

归一化（忽略 ε）:
 2 → (2-5)/2.24 ≈ -1.34
 4 → (4-5)/2.24 ≈ -0.45
 6 → (6-5)/2.24 ≈  0.45
 8 → (8-5)/2.24 ≈  1.34

假设学到的 γ=2、β=1，再缩放平移:
 2 → 2×(-1.34)+1 ≈ -1.68
 4 → 2×(-0.45)+1 ≈  0.11
 6 → 2×(0.45)+1  ≈  1.89
 8 → 2×(1.34)+1  ≈  3.68
```

做完后这批数据大致落在"以 0 为中心、尺度可控"的范围。

### 3.4 关键：推理时 BN 变成一次线性变换（NPU 视角的重头戏）

**训练和推理是两个世界。** 推理时，权重已固定，BN 里的 μ、σ²、γ、β **全是固定常数**。把公式展开：

```
y = γ·(x-μ)/√(σ²+ε) + β
  = (γ/√(σ²+ε))·x  +  (β - γ·μ/√(σ²+ε))
  =      α·x        +        c
```

BN 整个退化成 **`y = α·x + c`**——一次乘加。

### 3.5 BN 被"吸"进上一层权重（融合，手算）

既然 BN 只是 `y = αx + c`，那它完全可以和上一层的卷积/全连接合并，算出来的结果一模一样。

例：上一层全连接 `z = w·x + b`，设 `w=2, b=3`，即 `z = 2x + 3`。
BN 参数：`γ=2, β=1, μ=2, σ²=1`（忽略 ε）。

```
α = γ/√σ² = 2/1 = 2
c = β - α·μ = 1 - 2×2 = -3

BN 输出: y = α·z + c = 2z - 3

代入 z = 2x + 3:
y = 2(2x + 3) - 3 = 4x + 3
```

等价于**把 BN 直接写进上一层**：

```
新权重 w' = α·w = 2×2 = 4
新偏置 b' = α·b + c = 2×3 + (-3) = 3
新层: y = w'·x + b' = 4x + 3    ← 和原链路算出来一模一样
```

验证 `x=1`：

```
原链路: FC → 2×1+3 = 5，BN → 2×5-3 = 7
融合后: 4×1+3 = 7   ✓ 一致
```

### 3.6 这一步对 NPU 意味着什么（记住这句话）

> **推理时，BN 不存在的。** 模型导出/转换时，工具链已经把所有 BN 融合进相邻卷积/全连接的权重里了。

所以你看到的真实推理模型里，根本找不到"BN"这个算子——硬件上就**不需要为实现 BN 单独造电路**。这是"少一种算子 = 少一块电路"的直接体现。

## 四、与 NPU 的联系

### 4.1 池化的硬件代价

- **Max 池化**：一个比较器树。对窗口内几个数两两比大小，选出最大。**没有乘法**。
- **Average 池化**：加法器树 + 一次移位（除以 2² 就是右移 2 位）。也**没有乘法**。

池化窗口内每个数只用一次，**权重不用搬、输入也几乎不重复用** → 硬件上非常简单。相比卷积动不动几百个乘法器，池化是"顺手加几根线"的事。

### 4.2 归一化的硬件代价

训练时 BN 要算均值、方差，还挺费事。但**推理模型里 BN 已被融合，芯片根本不实现 BN**。真需要归一化算子的地方（比如 Transformer 的 LayerNorm，见下），硬件上就是一个"求均值 → 求方差 → 缩放平移"的小流水单元，计算量远小于卷积。

### 4.3 轻计算 vs 重计算

| 算子 | 计算类型 | 硬件开销 |
|---|---|---|
| 卷积 / 全连接 | 重（大量 MAC） | MAC 阵列，占芯片绝大部分面积 |
| 池化 | 轻（比较/平均） | 比较器、加法器树 |
| 归一化（推理） | 无（被融合） | 0，靠工具链提前吃掉 |

## 五、延伸：LLM 里的 LayerNorm（和你学的大模型联动）

Transformer（LLM 的基础结构）用的不是 BatchNorm，是 **LayerNorm（层归一化，LN）**。区别就一句话：

```
BatchNorm:  在一批样本之间，对"同一个通道"求均值/方差   ← 依赖 batch
LayerNorm:  在单个样本内部，对"各个特征"求均值/方差    ← 不依赖 batch
```

为什么 LLM 用 LN？

- LLM 推理时 batch 常常 = 1（一次生成一个词），BN 的"批量统计"根本没意义
- 句子有长有短，BN 跨样本统计不方便；LN 只看当前这个 token 自己的特征向量，稳定简单

**硬件上的区别（准确版）：**

```
BN:  μ、σ 是训练时统计好的常数 → 推理时被融合进权重，芯片上消失
LN:  μ、σ 要根据"当前输入"现场算 → 芯片上保留一个真实的归一化单元
     （对每个 token 的特征向量：求均值 → 求方差 → 归一化 → 乘γ加β）
```

所以如果将来你看到一个 NPU 框图里有 "Normalize" 单元，那就是为 Transformer/LN 这类"现场归一化"准备的——学完这课，你就知道它在算什么了。

## 七、练习

### 必做题

**① Max 池化**：手算下面 6×6 图，2×2 窗口，步长 2：

```
 2  4  1  3  8  6
 7  5  9  0  2  1
 3  8  4  6  7  5
 1  2  0  9  3  4
 5  6  7  8  1  2
 9  0  3  4  5  6
```

**② Average 池化**：用 ① 的图算一遍平均池化（不用全算，算第一行三个窗口即可）。

**③ BN 推理融合**：上一层全连接 `y = 3x + 1`，BN 参数 `γ=2, β=-1, μ=4, σ²=4`（忽略 ε）。求融合后的新权重 `w'` 和新偏置 `b'`，并写出最终表达式。

**④ 概念**：为什么推理模型里找不到 BN 算子？LN 为什么推理时芯片上还在？

### 思考题（挑战）

**⑤ 池化会改变通道数吗？** 一张 H×W×C 的特征图经过池化，输出形状是什么？结合卷积层的通道变化对比一下。

## 答案

<summary>展开对答案</summary>

**①**
```
窗口(1,1): 2 4 /7 5   → 7     窗口(1,2): 1 3 /9 0  → 9     窗口(1,3): 8 6 /2 1  → 8
窗口(2,1): 3 8 /1 2   → 8     窗口(2,2): 4 6 /0 9  → 9     窗口(2,3): 7 5 /3 4  → 7
窗口(3,1): 5 6 /9 0   → 9     窗口(3,2): 7 8 /3 4  → 8     窗口(3,3): 1 2 /5 6  → 6

输出:
  7  9  8
  8  9  7
  9  8  6
```

**②**
```
第一行三个窗口:
(2+4+7+5)/4 = 18/4 = 4.5
(1+3+9+0)/4 = 13/4 = 3.25
(8+6+2+1)/4 = 17/4 = 4.25
```

**③**
```
α = γ/√σ² = 2/2 = 1
c = β - α·μ = -1 - 1×4 = -5

w' = α·w = 1×3 = 3
b' = α·b + c = 1×1 + (-5) = -4

融合后: y = 3x - 4

验证 x=2: 原链路 3×2+1=7 → BN 1×7-5=2；融合 3×2-4=2 ✓
```

**④**
推理时 BN 的 μ、σ²、γ、β 全是固定常数，BN 退化成 `y = αx + c`，可被合并进相邻卷积/全连接的权重里。所以模型导出时 BN 就被"吃掉"了，推理图里不存在这个算子。
LN 的 μ、σ 要根据当前输入现场算（它不依赖 batch 统计），不能提前融合，所以芯片上要保留一个真实的归一化单元。

**⑤**
池化**不改变通道数**：`H×W×C → (H'×W')×C`，只是每个通道单独变小。而卷积层会改变通道数（用几个核就出几个通道）。原因是池化没有权重、逐通道独立处理，它不认识"跨通道"的信息。

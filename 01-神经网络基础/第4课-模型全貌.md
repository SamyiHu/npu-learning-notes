# 第 4 课笔记：模型全貌——把 CNN 零件箱拼成一张地图

> 学习日期：2026-08-06（2026-08 扩写：补残差、读图方法、YOLO 对照、推理数据流）
> 阶段：01-神经网络基础（收尾）
> 前提：已学神经元、线代、卷积、池化、归一化（第1~3课）
> 方式：对话式教学 + 复习测验，本课是把"零件"拼成"模型全貌"

---

## 一、核心一句话

**神经网络 = 一根管道（输入进去，结论出来）。每一层 = [线性变换（乘加）+ 激活（掰弯）]。**

模型文件里存的，就是管道里所有层的那一堆权重数字。跑模型 = 让输入顺着管道走一遍。

---

## 二、模型 = 管道；层 = 工序

- **神经网络** = 整根管道（所有工序合起来）
- **层** = 管道里的一道工序，输出接下一道工序的输入
- 层与层之间怎么连的规矩 = 权重数字

```
神经网络 = 一根管道
  ┌────────────────────────────────────────────┐
  │  工序1        工序2        工序3           │
  │  卷积层  →    卷积层  →    全连接层         │
  │  +激活        +激活        （输出层）        │
  │  +池化        +池化                        │
  └────────────────────────────────────────────┘
  每道工序 = 一层；所有层合起来 = 神经网络
```

### 一次前向，数据形状怎么变（以分类为例）

```
输入   224×224×3     原始像素
 ↓ 卷积堆（提特征，空间变小、通道变多）
特征图  7×7×512      "这里有没有某种模式"的热度
 ↓ 全连接 / 全局池化
向量   4096 → … → 1000   类别打分
```

**直觉：前半段把图"压"成特征，后半段把特征"拉"成结论。**  
空间分辨率下降、语义浓度上升——这是几乎所有视觉骨干的共同节奏。

---

## 三、管道分两段：找特征 → 做判断

```
前半段：找特征（看清输入里有什么）   → 用卷积层
后半段：做判断（根据特征下结论）     → 用全连接层
```

**卷积负责"看"，全连接负责"拍板"。** 所有识别类模型都是这个骨架。

> 现代检测/分割头可能不用巨大全连接，而用 1×1 卷积/转置卷积出图——但"特征段 + 决策段"的分工仍在。

---

## 四、每一层内部：线性变换 + 激活

- **线性变换 = 加权求和**（一堆乘加）
- 全连接层的线性变换 = 矩阵乘法（所有输入参与）
- **卷积层的线性变换 = 卷积（滑动点积）**——只有窗口内输入参与，本质是同一个东西的两种排法
- **激活函数每层都做，包括卷积层。** 否则多层线性 = 一层线性（塌缩成直线），表达不了复杂形状

```
全连接层 = [ 矩阵乘法（线性）] + [ ReLU（激活）]
卷积层   = [ 卷积（线性）]     + [ ReLU（激活）]
```

### 为什么必须有激活（精确版）

两层无激活：

```
y = W2 (W1 x) = (W2 W1) x = W' x     ← 仍是一层线性
```

加上 ReLU：

```
y = W2 · ReLU(W1 x)
```

中间出现"铰链"，多个铰链折线才能逼近复杂边界。  
**没有激活，深度失去意义；有激活，深度才买到表达力。**

> 池化、归一化是穿插的**辅助工序**，不属于"线性+激活"这套固定套路。

---

## 五、卷积层三性质（深化）

1. **局部视野**：3×3 核只看被盖住的 9 个像素
2. **权重共享**：同一个核全图滑动复用 → 参数永远 9 个，不随图变大而涨
3. **多核多特征**：16 个核 = 16 张特征图（"这里有没有特征X"的热度图）

**关键区分：参数 vs 计算量。**

- 图变大：卷积的**计算量**涨（滑过的窗口变多）
- 但**参数**不涨（还是那 9 个数字）

对比全连接：1000×1000 图 = 100 万像素，每个像素单独配权重 → 参数爆炸。卷积 9 个数解决。这就是为什么图片用卷积。

### 粗算一笔（建立数量级）

```
输入 224×224×3，64 个 3×3 核（SAME padding，输出仍 224×224）
参数 = 64 × (3×3×3) = 1728     ← 很小
MAC  ≈ 224×224 × 64 × 27 ≈ 0.87 亿  ← 不小
```

**参数少、计算多**——这是 NPU 存在的理由之一：权重可以驻留片上反复用，计算轰 MAC 阵列。

---

## 六、为什么图片不能只用全连接

1. **参数爆炸**：输入 × 神经元，动辄上亿参数
2. **浪费结构**：全连接把像素当独立个体，无视"相邻像素组成特征、特征处处可现"的规律

卷积把两条先验写进结构：**局部连接 + 权重共享**。  
先验越对，要学的参数越少，越不容易过拟合——这是"结构设计"在干的活。

---

## 七、现代 CNN 多出来的零件：残差（ResNet 一句话）

深层网络直接堆卷积会难训。ResNet 加捷径：

```
输出 = F(x) + x
```

- F 学"改动量"，原信号 x 有直达通道
- 解决"越深越差"，才能叠到几十上百层
- 推理时只是多一条加法支路——但数据要多搬一份 x（03 存储课会再会师）

**YOLO / ResNet / 大量骨干网都建立在"卷积 + BN折叠 + ReLU + 残差"上。**

---

## 八、用 YOLO 当"活教材"（为阶段四/五铺垫）

YOLO 不神秘，就是 CNN 零件箱 + 检测头：

```
输入 640×640×3
 ↓ Backbone（卷积/C3 堆叠，提特征，多尺度）
 ↓ Neck（融合深浅层特征）
 ↓ Head（每个尺度输出：框 + 物体分 + 类别）
CPU：decode 边界框 + NMS 去重
```

| 你在 01 学的 | 在 YOLO 里出现在哪 |
|---|---|
| 卷积 + ReLU | Backbone 主体 |
| BN | 训练有、推理折叠进卷积 |
| 池化 / stride=2 | 下采样 |
| 残差 | C3/CSP 结构内部 |
| 全连接 | 经常换成 1×1 卷积出预测 |

**里程碑升级：能"读"任何 CNN 结构图——认零件，不背层名。**

---

## 九、CNN 零件箱（里程碑）

```
卷积层      找特征（线性变换 = 滑动点积）
   + ReLU   掰弯
   + 池化   压缩（没权重，固定规则）
残差支路    原稿 + 修改（深层可训）
全连接层    判断
   + ReLU   掰弯
归一化 BN   稳数值（推理时被融合，模型里消失）
```

**任何 CNN（VGG、ResNet、YOLO）都是这几样拼出来的。学完本课，能"读"任何 CNN 模型的图。**

## 十、IC 验证视角

- 模型图 = 规格；层连接与形状是**断言可写死的不变式**（某层输出必须 7×7×512）
- 逐层输出对不齐时，先怀疑 **预处理/量化/布局**，再怀疑 MAC
- 金标准做法：PC 浮点模型当参考模型，硬件/量化模型逐层对比（阶段四 accuracy_analysis 同款思路）

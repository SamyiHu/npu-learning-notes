## 一、核心一句话

**神经网络推理 = 一堆矩阵乘法 + 一堆非线性映射。**
NPU 只做推理（权重固定），不参与训练（训练才用微积分），所以本路线**几乎不需要高数**。

---

## 二、第 1 课：神经元与全连接层

### 神经元 = 一次乘加（MAC）

```
y = w × x + b
```

- `x`：输入，`w`：权重（训练得到的参数），`b`：偏置，`y`：输出
- 一个神经元干的事：**一次乘法 + 一次加法** → 硬件上叫 **MAC（Multiply-Accumulate，乘累加）**

多输入神经元：

```
y = w₁x₁ + w₂x₂ + w₃x₃ + b      ← 本质是向量点积
```

### 激活函数

- 没有激活函数，多层线性叠加 = 还是线性函数 → 网络什么都学不了
- **ReLU**：`z>0 取 z，z≤0 取 0`。NPU 最爱的激活，硬件上只是一个"取较大值"的比较

### 全连接层 = 矩阵乘法

一层做的事：**权重矩阵 × 输入向量 + 偏置**。N 个神经元、M 个输入 → 需要 **N×M** 个权重。

### 训练 vs 推理

| | 训练 Training | 推理 Inference |
|---|---|---|
| 做什么 | 不断调整 w、b 让输出接近答案 | w、b 已固定，只用它们算结果 |
| 在哪做 | 服务器/数据中心（GPU） | 终端设备（NPU） |
| NPU 管吗 | 不管 | **只做这个** |

## 三、第 1.5 课：线性代数生存包（够用版）

### 1. 向量 = 一串数字
`今天状态 = [9, 6, 3]`（困/饿/累）

### 2. 矩阵 = 一张数字表格
记作 **行 × 列**。例：4 个神经元 × 3 个输入的权重表 = 4行3列矩阵。

### 3. 点积 = 对应相乘再相加
```
[9,6,3] · [1,2,3] = 9×1 + 6×2 + 3×3 = 30
```

### 4. 矩阵乘法（唯一规则，重点）

> **左矩阵的行 × 右矩阵的列，对应相乘再相加。**

例：
```
[1  2]   [5  6]     [1×5+2×7   1×6+2×8]     [19  22]
[3  4] × [7  8]  =  [3×5+4×7   3×6+4×8]  =  [43  50]
```

神经网络正确写法（**权重在左、输入在右**）：

```
   权重 W (4×3)         输入 x (3×1)        输出 y (4×1)
   ┌ 0.5  0.2  0.8 ┐    ┌ 9 ┐     ┌ 0.5×9+0.2×6+0.8×3 ┐
   │ 1.0  0.1  0.3 │ ×  │ 6 │  =  │ 1.0×9+0.1×6+0.3×3 │
   │ 0.2  0.4  0.6 │    └ 3 ┘     │ 0.2×9+0.4×6+0.6×3 │
   └ 0.9  0.5  0.7 ┘              └ 0.9×9+0.5×6+0.7×3 ┘
```

每个输出 = **取左矩阵的一行（一个神经元）** 和 **右矩阵的列（输入）** 做点积。

### 5. 维度规则与口诀

- **外号管结果，内号管能否**
- 结果形状 = (左的行数, 右的列数)
- 能否相乘 = 左的列数 == 右的行数
- **矩阵乘法不满足交换律**：`A×B ≠ B×A`，顺序反了甚至乘不了

### 6. 为什么 NPU 的灵魂是矩阵乘法
神经网络 = 一堆矩阵乘法 → 矩阵乘法 = 大量 MAC → NPU 堆满乘法器，用最快速度做这件事。

## 四、第 2 课：卷积层

### 图像的数据结构

- 灰度图 = 一张像素表（高×宽，1 通道）
- 彩色图 = 三张表叠放（高×宽×3 通道），通道数记作 C

### 卷积核（kernel / filter）

- 一小张**训练好的权重表**（如 2×2、3×3）
- 和全连接权重本质一样，只是**很小、且全图共用**

### 卷积运算 = 核在图上滑动，每个位置做一次点积

例：3×3 图，2×2 核，步长 1，无填充：

```
核 [1 2; 3 4]
图:
 1  2  3
 4  5  6
 7  8  9

窗口1 → 1×1+2×2+4×3+5×4 = 37     窗口2 → 2×1+3×2+5×3+6×4 = 47
窗口3 → 4×1+5×2+7×3+8×4 = 67     窗口4 → 5×1+6×2+8×3+9×4 = 77

输出特征图: 37 47
           67 77
```

### 三个关键直觉

1. **卷积核 = 特征探测器**：一个核检测一种特征（竖边、纹理……），多个核 → 多张特征图
2. **权重共享 = 参数极少**：全连接要 N×M 个权重，卷积只要核那么大，全图共用 → 解决大图像参数爆炸
3. **卷积 = 矩阵乘法**：把滑动窗口摊平（im2col），卷积就变成一张大矩阵乘法 → 和第 1.5 课无缝衔接

### 输出尺寸公式

```
输出尺寸 = (原图尺寸 - 核尺寸) / 步长 + 1    例: (3-2)/1+1 = 2
```

### 与 NPU 的联系

- 同一卷积核被全图反复复用 → 权重可一次搬进片上缓存反复用 → **大幅减少数据搬运**
- **NPU 设计的灵魂是减少数据搬运**（后文反复出现）

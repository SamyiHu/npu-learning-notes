## 〇、为什么要学这个？

第 1 课已经知道：**神经网络推理 = 一堆矩阵乘法 + 非线性映射**。

"一堆矩阵乘法"占神经网络 90% 以上的计算量。矩阵乘法就是线性代数里的一个操作。只需要学这一个操作，以及它为什么天然适合硬件。

---

## 一、向量：一串有顺序的数

### 直觉

点单记录 `[中杯, 美式, 加浓, 少冰]` —— 每个位置有固定含义，顺序不能乱。这就是向量：**一组有顺序的数**。

### 两种写法

```
行向量:  [9, 6, 3]           ← 横着写
列向量:  ┌ 9 ┐               ← 竖着写
         │ 6 │
         └ 3 ┘
```

**神经网络里输入 x 默认是列向量。**

### 维度

向量里有几个数，就叫几维向量。`[9, 6, 3]` 是 3 维。

---

## 二、点积：两个向量的"默契度"

### 直觉：加权总分

成绩 `[80, 90, 70]` × 学分 `[3, 4, 2]`：

```
80×3 + 90×4 + 70×2 = 240 + 360 + 140 = 740
```

**对应位置相乘，再加起来。** 这就是点积。

### 定义

```
a · b = a₁×b₁ + a₂×b₂ + ... + aₙ×bₙ
```

要求：两个向量**长度相同**。结果：**一个数**（不是向量）。

### 手算

```
[2, 3, 1] · [4, 0, 5] = 2×4 + 3×0 + 1×5 = 8 + 0 + 5 = 13
```

### 为什么叫"默契度"？

- 方向一致 → 点积**大**
- 方向相反 → 点积**负**
- 相互垂直 → 点积**0**

```
[5, 5] · [1, 1]  = 10    ← 方向一致
[5, 5] · [-1,-1] = -10   ← 方向相反
[5, 5] · [1,-1]  = 0     ← 垂直
```

这是"神经元如何检测特征"的数学根基。芯片里的 **MAC 就是在算点积**。

## 三、矩阵：一张数字表格

4 个神经元、每个接 3 个输入 → 4×3 = 12 个权重，排成表：

```
        输入1  输入2  输入3
神经元1 [ 0.5   0.2   0.8 ]
神经元2 [ 1.0   0.1   0.3 ]
神经元3 [ 0.2   0.4   0.6 ]
神经元4 [ 0.9   0.5   0.7 ]
```

记作 4×3（**行 × 列**）矩阵。

### 两种视角（重点）

**视角 A：一堆行向量的摞叠**

```
W = ┌── row₀ ──┐     ← 第 0 个神经元的全部权重
    ├── row₁ ──┤
    ├── row₂ ──┤
    └── row₃ ──┘
```

**视角 B：一堆列向量的横排**

```
W = [ col₀  col₁  col₂ ]     ← 每个输入在所有神经元上的权重
```

做矩阵乘法时默认用视角 A：**一行一行取**。每行 = 一个神经元的权重 = 和输入做一次点积 → 得到一个输出。

---

## 四、矩阵 × 向量：一个全连接层

### 这就是全连接层

```
        W (4×3)       ×    x (3×1)    =    y (4×1)

   ┌ 0.5  0.2  0.8 ┐       ┌ 9 ┐          ┌ y₀ ┐
   │ 1.0  0.1  0.3 │   ×   │ 6 │     =    │ y₁ │
   │ 0.2  0.4  0.6 │       └ 3 ┘          │ y₂ │
   └ 0.9  0.5  0.7 ┘                      └ y₃ ┘
```

**规则：W 的每一行，和 x 做一次点积，得到 y 的一个元素。**

### 逐个手算

```
y₀ = [0.5, 0.2, 0.8] · [9, 6, 3] = 4.5 + 1.2 + 2.4 = 8.1
y₁ = [1.0, 0.1, 0.3] · [9, 6, 3] = 9.0 + 0.6 + 0.9 = 10.5
y₂ = [0.2, 0.4, 0.6] · [9, 6, 3] = 1.8 + 2.4 + 1.8 = 6.0
y₃ = [0.9, 0.5, 0.7] · [9, 6, 3] = 8.1 + 3.0 + 2.1 = 13.2
```

```
y = ┌  8.1 ┐      ← 神经元 0 的输出
    │ 10.5 │      ← 神经元 1 的输出（对这个输入"最兴奋"）
    │  6.0 │
    └ 13.2 ┘      ← 神经元 3 的输出
```

**4 行 = 4 个点积 = 4 个神经元的输出。**

## 五、矩阵 × 矩阵：一次算多个样本

两个样本拼成 3×2 的矩阵，一次算完：

```
    W (4×3)       ×      X (3×2)       =      Y (4×2)

┌ 0.5 0.2 0.8 ┐      ┌ 9   1 ┐        ┌ 8.1   ?  ┐
│ 1.0 0.1 0.3 │  ×   │ 6   2 │   =    │10.5   ?  │
│ 0.2 0.4 0.6 │      └ 3   3 ┘        │ 6.0   ?  │
└ 0.9 0.5 0.7 ┘                        └13.2   ?  ┘
```

**规则：Y 的第 i 行第 j 列 = W 的第 i 行 · X 的第 j 列。**

第二个样本 x = [1, 2, 3]ᵀ：

```
Y[0][1] = 0.5×1 + 0.2×2 + 0.8×3 = 0.5 + 0.4 + 2.4 = 3.3
Y[1][1] = 1.0×1 + 0.1×2 + 0.3×3 = 1.0 + 0.2 + 0.9 = 2.1
Y[2][1] = 0.2×1 + 0.4×2 + 0.6×3 = 0.2 + 0.8 + 1.8 = 2.8
Y[3][1] = 0.9×1 + 0.5×2 + 0.7×3 = 0.9 + 1.0 + 2.1 = 4.0
```

```
    ┌ 8.1   3.3 ┐
Y = │10.5   2.1 │
    │ 6.0   2.8 │
    └13.2   4.0 ┘
```

### 更一般的矩阵乘法

```
A (2×3)       ×       B (3×2)       =       C (2×2)

┌ 1  2  3 ┐        ┌ 7   8 ┐          ┌ ?   ? ┐
└ 4  5  6 ┘   ×    │ 9  10 │     =    └ ?   ? ┘
                   └11  12 ┘
```

```
C[0][0] = [1,2,3] · [7,9,11]  = 1×7 + 2×9 + 3×11  = 7+18+33  = 58
C[0][1] = [1,2,3] · [8,10,12] = 1×8 + 2×10 + 3×12 = 8+20+36  = 64
C[1][0] = [4,5,6] · [7,9,11]  = 4×7 + 5×9 + 6×11  = 28+45+66 = 139
C[1][1] = [4,5,6] · [8,10,12] = 4×8 + 5×10 + 6×12 = 32+50+72 = 154
```

```
C = ┌ 58   64 ┐
    └139  154 ┘
```

>                └2 3┘   └7 8┘

## 六、维度口诀

```
结果形状:  (左行数, 右列数)
能否相乘:   左列数 == 右行数
```

```
       必须相等
          ↓
A(m×n)  ×  B(n×p)  =  C(m×p)
   ↑                ↑
   结果形状 = 两个外号
```

自测：

| 算式 | 能乘吗？ | 结果形状 |
|---|---|---|
| (3×4) × (4×2) | 能（内 4=4） | 3×2 |
| (2×5) × (3×5) | **不能**（内 5≠3） | — |
| (5×1) × (1×5) | 能（内 1=1） | 5×5 |
| (1×5) × (5×1) | 能（内 5=5） | 1×1（一个数） |

注意最后两行：**顺序一换，结果完全不同**（5×5 vs 1×1）。

## 七、三条必须知道的规矩

### 1. 不满足交换律

```
A × B ≠ B × A
```

多数情况换边后根本乘不了（维度对不上）。即使碰巧能乘，结果通常也不同。

### 2. 满足结合律

```
(A × B) × C = A × (B × C)
```

乘法可以"重新分组"而不改变结果 → 硬件可以**先算更省的那组**，或**切块分组计算**。这是分块（tiling）的数学依据。

### 3. 转置

```
(A × B)ᵀ = Bᵀ × Aᵀ
```

转置 = 行列互换，(m×n) → (n×m)。后面理解卷积与全连接互换时会用到。

## 八、深度扩展：为什么矩阵乘法是 NPU 的灵魂

### 8.1 天生并行：每个输出元素互不依赖

```
y₀ = row₀ · x      ← 只用到 row₀ 和 x
y₁ = row₁ · x      ← 只用到 row₁ 和 x
y₂ = row₂ · x      ← 只用到 row₂ 和 x
y₃ = row₃ · x      ← 只用到 row₃ 和 x
```

**四个点积互不依赖，可以同时算。** NPU 据此做 MAC 阵列：每行权重配一组乘法器，并行算多个点积；点积内部还可以流水线（乘法器后面挂加法树）。

```
行0: [w₀₀ w₀₁ w₀₂]  →  ×  →  +  →  y₀
行1: [w₁₀ w₁₁ w₁₂]  →  ×  →  +  →  y₁   }  全并行
行2: [w₂₀ w₂₁ w₂₂]  →  ×  →  +  →  y₂
行3: [w₃₀ w₃₁ w₃₂]  →  ×  →  +  →  y₃
```

这就是"NPU 堆多少乘法器就快多少倍"的数学根源。

### 8.2 数据复用：每个数被反复用

以 W(4×3) × x(3×1) 为例：

```
每个权重 wᵢⱼ 被用了 1 次（在自己的点积里）
每个输入  xⱼ  被用了 4 次（在每一行的点积里）
```

一次算两个样本时（W(4×3) × X(3×2)）：每个权重被用 2 次，每个输入仍被用 4 次。

**数据搬进片上 SRAM 后反复使用，不用频繁访问外部 DDR** —— 这是"灵魂是减少数据搬运"的数学依据。

### 8.3 分块（Tiling）：大矩阵的"切蛋糕"

神经网络矩阵往往巨大，NPU 片上 SRAM 只有几百 KB。把大矩阵切成小块，每次搬一小块进片上：

```
┌            ┐       ┌──┬──┐
│  大矩阵 A  │   →   │A₁│A₂│    切！每次搬一小块
└            ┘       ├──┼──┤
                     │A₃│A₄│
                     └──┴──┘
```

结合律保证了"切块分别乘再加起来，结果不变"。编译器/驱动负责切，代价是多搬几次数据。

### 8.4 GEMM：计算机科学里被优化得最狠的函数

General Matrix Multiply（通用矩阵乘法）。软件里的经典优化，NPU 把它们烧成电路：

| 软件优化 | NPU 硬件对应 |
|---|---|
| 循环重排 | **数据流**（权重固定 / 输出固定 / 行固定） |
| 分块 | 片上 SRAM + DMA 引擎分块搬运 |
| SIMD 向量化 | **MAC 阵列**（一排乘法器并行） |
| 预取 | DMA 双缓冲（算当前块，搬下一块） |

理解了这条，后面看"脉动阵列"就不会觉得是凭空冒出来的——它就是为矩阵乘法量身定制的硬件结构。

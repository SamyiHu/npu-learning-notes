## 一、板子与资料全景（DshanPi-A1）

### 硬件规格（与你学习路线相关的部分）

| 项 | 规格 | 对你意味着什么 |
|---|---|---|
| SoC | RK3576：4×A72 + 4×A53，6 TOPS NPU | 与上手指引/03 第 3 课完全一致，双核 core_mask、W4A16 全可玩 |
| NPU 数据类型 | INT4/INT8/INT16/FP16 | 混合量化（02 第 1 课）实验全支持 |
| GPU | Mali-G52（RK3576 官方口径 MC3；板卡页只写 "3D GPU"） | 与 NPU 无关，跑桌面用 |
| 内存 | **6GB / 8GB LPDDR 两个版本** | 决定 LLM 实验上限：6G ≤3B、8G 可试 7B（详见上手指引第 6 节） |
| 存储 | 无 eMMC（TF 启动）/ 64GB eMMC 两个版本 | 无 eMMC 版认准高速 TF 卡 |
| 视频输入 | **Micro HDMI IN（可当采集卡）** + MIPI 摄像头（IMX415，Buildroot 系统） | 做视觉实验不用额外买 USB 摄像头 |
| 网络 | 双千兆网口 + WiFi6（PCIe rtl8852ae）+ BT5 | 联调 ssh 舒服 |
| 供电 | **Type-C PD ≥30W，硬性要求**（非 PD 或 <30W 会不稳，保修除外） | 上手指引第 2 节已强调 |
| 参考 | 接口还有 USB3.0（其一支持 DP 输出）、PCIe、40-pin GPIO、M.2 Key-E（背面）、风扇接口 | — |

> 首件事：**确认你拿到的是 6G 还是 8G、有无 eMMC 版本**（看包装/订单即可），写进问答收录，LLM 实验选型要用。

| 资源 | 入口 |

> **一个容易混的点**：DshanPi-A1 官方系统叫"ArmbianOS"，是百问网**自维护**的 Armbian 定制版（BSP 内核 + rknpu 驱动）；它和 armbian.com 社区通用镜像不是一回事。后者/主线内核至今没有 RK3576 NPU 支持。**认准 dl.100ask.net 下载就不会踩坑**（上手指引坑清单第 2 条已按此修正）。

三条版本事实（与你笔记对表）：

1. **RKNN 教程用的正是 rknn-toolkit2 v2.3.2**——和 04 讲义、上手指引同版本，命令可直接对照抄
2. 板端支持 rknn_toolkit_lite2（Python）+ librknnrt（C）两条推理路径，FAQ 里连 onnxoptimizer 编译失败都给了处置步骤——踩坑预案比官方文档还细
3. 生成式 AI 章节走 rknn-llm（DeepSeek-R1 / Qwen-VL 多模态），对应上手指引第 6 节

## 五、使用建议（时间线）

**到手前（现在）**

1. 读 QuickStart 三页：ResourceAcquisition（资料清单）→ HardwareConnectionGuide（接线/供电）→ InitialBootSetup（首次启动向导：需接显示器+键鼠，设 root 密码、建用户、连 WiFi）
2. 环境直接照 AppDev 3-3-1 搭 WSL（v2.3.2，与 04 讲义命令一致），把 YOLOv8n 转换+仿真跑通
3. 对照上手指引第 1、2、8 节做认知校准和采购核对（PD 30W 电源、Type-C 3.2 10Gbps 线）

**到手 Day 1**

4. 上手指引第四节"开箱四步"（ArmbianOS 首次启动向导 → ssh → 优先查 /sys/kernel/debug/rknpu/version）
5. 上手指引第五节 YOLOv5s 全链路 ≈ 百问网 3-3-4 目标检测章，两边对照着做

**之后（按对齐表按需取用，不从头刷）**

6. 双核实验：上手指引第五节 core_mask 对照表 + ProjectDev"多线程推理"章
7. LLM：3-4 章 DeepSeek-R1/Qwen-VL + 上手指引第六节性能预期表
8. 驱动深潜：LDDBasic HelloDriver/设备树 → 回看 07 第 3 课 rknpu 驱动拆解
9. 视频：只在文档看不懂或想看效果演示时，B 站搜对应主题（如"韦东山 小智 DshanPI-A1"）
